## 🌟 Overview

**[PhysicalAI Hub](https://physicalaidirectory.com)** (`physicalaidirectory.com`) is the premier independent database, technical specifications comparison engine, and commercial procurement directory for the **Physical AI & Humanoid Robotics** industry in 2026.

As embodied intelligence transitions from academic laboratories into automotive assembly lines and commercial enterprises, PhysicalAI Hub provides engineers, procurement teams, and robotics enthusiasts with verified, transparent hardware data.

---

## ✨ Key Features

- 🤖 **Comprehensive Hardware Database**: Detailed profiles for commercial and open-source humanoid robots including Unitree G1, Tesla Optimus Gen 2, Figure 02, Boston Dynamics Electric Atlas, 1X NEO Beta, and Agility Digit.
- ⚡ **Side-by-Side Comparison Engine**: Sub-second matrix comparing Degrees of Freedom (DoF), walking speeds, payloads, battery runtimes, and commercial pricing.
- 🎥 **Real Hardware Video Demos**: Integrated high-definition test footage and video walkthroughs directly embedded in product cards.
- 🌐 **Global Multilingual Support**: Seamless instant switching between **English**, **简体中文**, and **日本語** with localized terminology and regional pricing.
- 📑 **Direct RFQ Procurement System**: Verified quotation requests connecting enterprise buyers with certified robotics distributors and OEMs.
- 🚀 **Maximized Technical SEO**:
  - Full Schema.org `Product`, `ItemPage`, and `WebSite` JSON-LD structured data.
  - Sub-second Core Web Vitals performance with Next.js App Router and Turbopack.
  - Automated `sitemap.xml` and instant `IndexNow` broadcast engine.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router, Server Components)
- **Styling**: Tailwind CSS, Lucide React Icons
- **Deployment**: Vercel Global Edge Network with SSL
- **SEO & Indexing**: IndexNow API, Google Search Console, OpenGraph 2.0

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/SteveAiPro/physical-ai-hub.git
cd physical-ai-hub

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
